Entry for make.fun's **The Robot Pickup Line Championship** — the
funniest one-line pickup line a robot could use. The program writes a
single line to `/output/entry.txt`: a courtship protocol that allows
exactly one coffee query, and reads a no as a graceful retreat rather
than a reason to patch itself and ask again.

## Why this line

The humour is machine-native — protocols, queries and firmware — and
the charm is in the restraint: the robot is likeable because its
programming makes persistence impossible.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no network, deterministic: two runs
write identical bytes. `test_entry.py` checks the output is a single
line of 1–200 characters.
